## SussyBaka Feature

A fun application that detects "sus" behavior and "baka" levels!

### What is SussyBaka?

SussyBaka is a playful combination of:
- **Sus** - suspicious behavior (popularized by Among Us)
- **Baka** - Japanese word for fool/idiot (from anime culture)

### Usage

Run the SussyBaka detector in demo mode:
```bash
python3 sussybaka.py
```

Run in interactive mode:
```bash
python3 sussybaka.py --interactive
```

### Features

- 🔍 **Sus Detection**: Analyzes actions for suspicious keywords
- 🧠 **Baka Level Check**: Evaluates intelligence scores
- 🎯 **Final Verdict**: Provides an overall sussybaka rating
